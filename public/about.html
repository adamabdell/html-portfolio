About Me

Adam is a backend-focused software engineer with roughly five years of experience building data-driven applications, APIs, and automation pipelines across fintech, retail, and manufacturing environments. His core strength is Python development, particularly building REST APIs with FastAPI for both frontend integration and microservice-to-microservice communication, often incorporating asynchronous calls for performance. He pairs this with strong data manipulation skills using Pandas, NumPy, and SciPy — whether cleaning inventory data pulled into dataframes, running statistical comparisons across retirement simulation strategies, or transforming multi-database records into production planning reports. He's comfortable across the full data lifecycle: querying complex SQL and PostgreSQL databases, designing schemas, and building forecasting models with Prophet for real-world sales data.

On the infrastructure and DevOps side, Adam has hands-on experience deploying and debugging AWS Lambda functions (triggered via EventBridge or API calls, monitored through CloudWatch), managing data storage in S3, and automating deployments through CI/CD pipelines using GitHub Workflows. He containerizes applications with Docker to replicate production database schemas for reliable testing, and writes thorough unit, functional, and end-to-end test suites with Pytest — reflecting a disciplined, quality-first approach to shipping code.

A distinguishing piece of his experience is applied AI integration: he designed a multi-agent n8n chatbot architecture where AI agents interpret natural language, route requests to the correct domain (inventory, sales, invoices), generate SQL queries dynamically, and summarize results back to the user — essentially building a RAG-capable, tool-using AI system on top of his own API endpoints. He's also used AI-assisted tools like GitHub Copilot and Claude.ai to refactor and optimize existing codebases. Rounding this out, he brings reporting and analytics experience (Power BI, Excel, Jupyter Notebook) and academic depth from an M.S. in Computer Science focused on Machine Learning, giving him a solid grounding in data mining, clustering, and probabilistic modeling techniques like Hidden Markov Models.
